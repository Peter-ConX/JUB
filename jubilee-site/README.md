## Tech Stack

- Next.js 15 (App Router)
- Tailwind CSS 4
- Framer Motion
- Cormorant Garamond + DM Sans typography

## Run Locally

```bash
cd jubilee-site
npm install
npm run dev
```

## Deploy (Vercel)

Set **Root Directory** to `jubilee-site`.
